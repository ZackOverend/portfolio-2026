# portfolio-2026

Personal portfolio site for Zackary Overend, 4th year computer science student and developer focused on building clean, intuitive applications across mobile and web.

The site features a home page with a hero, project showcase, and contact section, alongside individual case-study pages for each featured project.

## Projects Featured

- **NoWasteMate** - iOS food waste manager (SwiftUI, FastAPI, Firebase, TensorFlow)
- **Image-In** - drag & drop image content analysis website (Next.js, C# API)
- **INDStudio 51** - business site rebuild with responsive layout (Next.js, UI/UX)
- **Nova Weather** - weather app with custom API and cloud integration (Flutter, Python, Azure)
